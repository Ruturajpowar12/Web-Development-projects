# 💰 Expense Tracker

A simple **Expense Tracker** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- ➕ Add expenses
- 📝 Add expense description
- 💰 Calculate total amount
- 🗑️ Delete expenses
- 💾 Store expenses in Local Storage
- 🔄 Data remains after refreshing the page
- 🎨 Simple and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
