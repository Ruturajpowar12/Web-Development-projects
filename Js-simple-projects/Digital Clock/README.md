# ⏰ 12-Hour Digital Clock

A clean, modern digital clock web application featuring a vibrant gradient background and a 12-hour format with zero-padded values.

![Digital Clock Preview](/Js-simple-projects/Digital%20Clock/Screenshot%202026-06-06%20133439.png)

## 🚀 Features

- **12-Hour Format:** Automatically converts standard 24-hour time to a user-friendly 12-hour display.
- **Zero Padding:** Ensures single-digit hours, minutes, and seconds always display with a leading zero (e.g., `01` instead of `1`).
- **Real-time Updates:** Smoothly updates every single second.
- **Modern UI:** Features a vibrant linear gradient background, sleek card layouts, soft drop shadows, and elegant typography.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for the clock cards.
- **CSS3:** Custom styling, Flexbox layout, and linear gradients.
- **JavaScript (ES6):** Dynamic time tracking using `setInterval` and the native `Date` object.
