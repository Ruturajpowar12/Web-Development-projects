# 📊 Color Changer App

A simple, interactive web application built with HTML, CSS, and JavaScript. This project features a functional digital counter with boundary controls and a dynamic background color switcher.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure of the application.
- **CSS3:** Custom layout design, hover transitions, and visual state indicators.
- **JavaScript (ES6+):** DOM manipulation, event listeners, and array indexing logic.

## 📂 Project Structure

```text
├── index.html   # Main HTML document
├── style.css    # UI styling and layout rules
└── app.js       # Core application logic
```
