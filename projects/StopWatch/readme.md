# Stop Watch ⏱️

A simple stopwatch project built using **HTML, CSS, and JavaScript**.

### Features

- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Shows hours, minutes, and seconds

### Technologies

- HTML
- CSS
- JavaScript
