# Netflix Clone

A simple Netflix clone built with HTML and CSS.

## Description

This project is a static web page that mimics the Netflix homepage design. It includes a header with navigation, a hero section, and sections for different content categories.

## Features

- Responsive design
- Netflix-inspired layout
- Navigation menu
- Hero banner
- Content rows

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Clone or download the repository
2. Open `index.html` in your web browser
